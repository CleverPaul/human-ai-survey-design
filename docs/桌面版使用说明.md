# 双击运行桌面版

从仓库的 Releases 下载 `SurveyDesignLab.exe`，然后双击。也可以直接打开本地构建的 `code\dist\SurveyDesignLab.exe`。不需要安装 Python、配置 conda 或 Gurobi，也不需要打开浏览器。程序在自己的窗口中显示界面，计算在本机完成，不连接 LLM 服务。

单文件版启动时需要先解压内置运行库，请等窗口出现。也可以使用 `SurveyDesignLab-portable.zip`：先完整解压，再双击文件夹内的 `SurveyDesignLab.exe`。文件夹版的 `_internal` 目录必须保留，不能只取出其中的 exe。

## 建议的演示顺序

1. 先看默认结果：12 个真人、8 个候选画像、AI 预算 3、允许距离 0.080。程序会自动求解。
2. 切换 Group A / Group B，在偏差曲线上移动或拖动鼠标，查看不同年龄的去偏值和模型区间。
3. 调整预算或允许距离，点击 **Optimize the design**。通过 Age / Group / Weights 比较目标构成与优化后的权重。
4. 调整真人覆盖范围或人数，程序会重新生成数据、拟合偏差模型并求解。
5. 展开底部 trade-off 面板，点击按钮查看固定数据和预算下的风险曲线。
6. 点击 **Download run**，在 Windows 保存窗口中选择 JSON 文件位置。取消保存也可以继续操作。

桌面版内置免费 SCIP 求解器，求解的目标函数和约束与 Python 版相同。达到时间上限时，界面会标明当前是可行解，并显示求解间隙；不会把它写成已经证明的最优解。

## 当前示例的含义

默认选中 3 个 AI 画像，AI 回答承担约 24.2% 的总估计权重。AI 的人数和计入权重是两回事。更接近目标人群，并不意味着回答更可信；两个风险需要一起权衡。

数据均为仿真，去偏模型是非线性贝叶斯样条/GAM，尚不是 BART。模型区间依赖拟合假设，不能保证所有外推都准确。

关闭窗口即可退出。若程序异常，日志位于 `%LOCALAPPDATA%\SurveyDesignLab\logs\desktop.log`。重建步骤见 `desktop\BUILD.md`，验证记录见 `docs\desktop_validation.md`。
