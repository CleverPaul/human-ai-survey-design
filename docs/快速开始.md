# 本地演示

**无需 Python 的桌面版：** 从仓库 Releases 下载 `SurveyDesignLab.exe`，双击后直接在程序窗口内使用。本地构建文件在 `code\dist`。也可以解压 `SurveyDesignLab-portable.zip` 后运行其中的 exe。详见[桌面版使用说明](桌面版使用说明.md)。

以下是保留的 Python／浏览器运行方式。

安装 Python 3.10 或更新版本后，在项目根目录打开 PowerShell，执行：

```powershell
python -m pip install -r requirements-demo.txt
python app.py
```

浏览器打开 **http://127.0.0.1:8765**。也可以运行 `run_demo.ps1`。关闭程序时在运行窗口按 Ctrl+C。

建议先看默认示例：12 个真人、8 个候选目标画像、AI 预算 3、允许距离 .080。切换 Group B，在曲线上拖动鼠标，观察不同年龄的去偏值与模型区间。切换 Age / Group / Weights 查看最终样本构成。

将预算改为 0 并求解，会看到当前约束不可行；把允许距离放宽至 .250，可以只用真人。展开最下方的 trade-off 面板，可以求解固定数据与模型下的风险曲线。Download run 可下载完整 JSON。

注意三个区别：

- 蓝点是同画像 AI 回答减去真人回答，不是已经知道的真实偏差。
- 橙色区间表示拟合模型对偏差的认知不确定性，不包括一个新 AI 回答的全部随机波动。
- AI 的人数与最终计入权重不同；默认选中 3 个画像，但只承担约 24.2% 的估计权重。

默认结果中，AI 改善了画像匹配，但响应风险比原始真人等权估计更高。这正是要展示的张力。它在这一次仿真中也更接近目标均值，但不能把一次结果当作普遍有效的证据。

当前去偏实现是非线性贝叶斯样条/GAM，不是 BART。数据完全仿真，不调用真实 LLM；模型不确定性需要后续用实际数据验证。
